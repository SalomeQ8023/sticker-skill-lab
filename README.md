# 球的贴纸 Skill 实验室

这里收集由「球是发散家」制作的公开贴纸 Skill。上传自己的照片，让 Codex 帮你生成可以继续组合、裁切和使用的手账素材。

## 公开体验

### 稚拙蜡笔 3+7 手账套装

上传一张主体明确的单人物或单宠物照片，生成：

- 3 个主体主元素
- 7 个关联、记录、分区或点缀素材
- 1 张预览图
- 1 张透明底 PNG 母版
- 10 张独立透明 PNG

## 安装

把下面的链接发给 Codex，并说“请从这个 GitHub 链接安装 Skill”：

```text
https://github.com/SalomeQ8023/sticker-skill-lab/tree/main/skills/naive-crayon-sticker-set
```

安装完成后，继续在 Codex 中发送下面这句话：

```text
用 $naive-crayon-sticker-set 把我上传的人物或宠物照片做成 3+7 透明手账贴纸套装。
```

## 输入范围

- 当前支持：一张主体明确的单人物或单宠物照片。
- 暂不支持：多人、多宠物、人物与宠物并存，以及咖啡、背包、食物、地点等非人物／宠物主体。
- 照片会由 AI 图像生成服务处理。请只上传自己拥有必要使用权的照片；涉及他人或未成年人时，请先取得相应授权。

## 公开体验版说明

- 当前是公开体验版，不代表所有人物、宠物或重复运行都能得到完全一致的结果。
- 部分原本计划直接融入手账页面的连接线、分区或底纹，仍可能带有米白色外圈切边。
- 生成内容由 AI 辅助完成。请在正式使用前自行检查主体相似度、审美与透明背景。
