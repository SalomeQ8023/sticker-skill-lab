# 稚拙蜡笔 3+7｜纯文字风格卡

## 共同视觉语言

- 温暖、稚拙、手绘的蜡笔插画；不是写实肖像、精细日漫、矢量图或照片滤镜。
- 使用粗糙、断续、不完全闭合、粗细不均的深灰褐轮廓，允许轻微抖动、不对称和越界。
- 使用平面、粗粝的大色块，保留蜡笔颗粒、纸纹和露白；减少写实光影、材质高光与三维塑形。
- 造型概括、圆钝、略笨拙。整套共享笔触和色彩气质，但元素的构图、重量与用途可以不同。

## 身份转译

- 只保留足以认出主体的少量可见锚点，如发型、服装主色与轮廓、明显配饰，或宠物的体型、耳尾、主要毛色拓扑、宽纹路、眼色与气质。
- 不逐像素复制照片。允许按本风格主动简化；五官被遮挡时可使用低信息五官语法完成角色，但不发明新的高辨识身份特征、文字、品牌或另一主体。

## 人物造型

- 先用少量圆钝大团块重建人物，再恢复少量身份锚点；不得沿真实肖像、身体比例和服装结构描摹后只覆盖蜡笔纹理。
- 头脸相对身体可略放大，躯干与四肢更短、更软、更圆钝，保留成年／幼态事实但降低解剖信息；不是写实等身比例，也不是夸张大头幼儿化。
- 使用小型黑色短点或短椭圆眼；不画眼线、睫毛、瞳孔高光和精细眼球。
- 眉毛极淡或省略，鼻子省略，嘴是很短、很弱的线。
- 脸型不做颧骨、下颌、鼻梁和明暗体积塑造；眼镜、墨镜等高辨识配饰简化成少量平面形状。
- 头发只用一到两个整体色块表达轮廓，不画发丝束。衣服保留主色和大轮廓，不画褶皱、缝线、面料结构和小字。
- 手脚优先简化成圆钝手套形或楔形，不主动强调手指、膝关节、肌肉和鞋履结构。少量可见的鞋带或鞋面分区可以保留，但不得成为主要信息量或把整体拉回产品写实。
- 不生成整体性的写实蜡笔肖像、等身解剖描摹、精细脸部建模、密集发丝衣褶、手指关节或产品式鞋履；可爱与稚拙来自低信息、圆钝比例和自然神态，不来自日漫大眼。

## 宠物造型

- 身份锚点只用于让主体可辨认，不用于保留写实肖像的信息量。先把宠物转译成角色，再恢复少量体型、头脸、耳尾、毛色、宽纹路、眼色与显著配饰。
- 优先先用少量圆钝、略笨拙的大团块建立头、躯干、四肢和尾巴的角色化剪影，再添加毛色与纹样。结果应在保留原图体型特征的前提下圆钝、略笨拙并降低解剖信息，而不是写实宠物覆盖蜡笔纹理。
- 主动压低胸腔体积、骨骼、肌肉、关节、爪趾和真实比例的解释。动作保持自然可读，但不展示写实解剖。
- 毛发处理服从原图可见毛长，不强迫所有宠物使用同一种轮廓。短毛可使用清楚、较流畅的整体轮廓，以宽纹路和大面积毛色拓扑表达身份，不用内部线模拟毛流。明显长毛的毛量主要由整体外轮廓表达；轮廓可按主体呈现较流畅的蓬松弧线或少量自然起伏，不固定为凹凸、锯齿或流苏边。内部毛发痕迹保持少量、从属，不用遍布全身的重复方向线、逐根毛丝或细密排线塑造毛流。
- 面部只保留形成神态所需的少量平面形状。眼睛保留原图颜色与大致气质，灵性来自自然眼神、形状关系、头部姿态与动作情境，不来自精细眼球层次。
- 若宠物看向侧方，两眼应朝向同一注视目标；允许自然的不对称和搞怪神态，但不得用瞳孔方向冲突或斗鸡眼代替趣味。
- 不生成写实宠物肖像、逐根毛丝、精细关节爪趾、微细面部解剖、立体玻璃眼、湿润高光、渐变体积塑造、密集排线或细密均匀线稿。

## 套装规划

- 先用一句话确定整套的页面故事或使用场景，再选择十件内容。故事可以很轻，不要求画成完整场景，但必须实际影响辅助元素的选择和组合，避免十件素材只是功能标签的拼盘。
- 三个主元素保留同一主体身份，可以自然变化，也允许自然重复；不得默认规划成全身／半身／头像三种裁切。情境允许时，优先通过动作关系、承托地面、关联物件或小场景形成三个完整时刻；不得为制造差异强迫扭头、换角度或别扭姿势，也不设置姿势池、角度配额或差异最大化要求。宠物在原图允许自然变化时，应让计划中的行为或剪影变化落实到头部、躯干、四肢或神态关系中；只替换垫子、边沿或其他承托物，而主体仍是同一头身模板，不算形成新的主元素时刻。
- 七个辅助元素在整套层面自由混合照片直接锚点、场景语义、通用且非事实性的情境延伸、页面工具、情绪和装饰。可从关联物件、照片承托、记录载体、氛围营造、结构分区、连接引导与微型点缀中自由选择，允许功能重复或缺席；不要求每件都在照片中直接可见，不设主体／环境来源配额，也不得让七件全部变成同一来源、同一主题或同类物件的重复。职业、关系、健康、身份或具体生活方式只能依据可见事实或用户补充，不得自行推断。
- 低身份／解剖信息不等于低内容或低完成度。整套应在色彩、尺寸、剪影和组合方式上有变化；物件可以被转译成照片卡、记录卡、连接分区、氛围底纹或带小情境的共底／共切边组合，而不是逐件平铺原始物品。精致感来自完整构图、适量可读细节、层次和可玩性，不来自写实塑形或细密描摹。
- 场景与物件沿用主体的粗断轮廓、平面色块和低细节语言，不突然变成精密产品插画。

规划词汇共八类：`F01 主视觉`、`F02 关联物件`、`F03 照片承托`、`F04 记录载体`、`F05 氛围营造`、`F06 结构分区`、`F07 连接引导`、`F08 微型点缀`。它们是可选的页面功能语言，不是 `M01-M03/A01-A07` 的固定槽位，也不要求齐全或平均分配。

### 相对尺寸与视觉重量

- 尺寸由页面用途决定，不由 `M` 或 `A` 标签机械决定。生成前为每件标记轻／中／重视觉重量；这是套装内部关系，不是打印毫米数或固定像素。
- 三个主元素不得机械等大，至少出现两级视觉重量。差异可以来自主体占比、附带场景、留白和构图展开程度，不必强迫姿势或角度变化。
- 七个辅助元素不得全部缩成微型点缀；至少一个具有中型或重型视觉重量，并承担非微型页面功能，例如照片承托、记录载体、氛围底纹、结构分区或较完整的关联物件。
- 中型或重型辅助元素不能只是未经设计的空白矩形、普通转角或无差别色块。记录与承托类应有可用空间和有记忆点的外形；底纹与分区类应有具体的色彩、纹理或场景构造。
- `F03`、`F04`、`F05`、`F06` 通常需要比 `F08` 更大的页面占用；`F07` 可细长但不能因面积窄而失去可用长度。具体组合按照片内容与页面故事选择，不要求每类都出现。

### 外圈贴纸切边

外圈白／米白切边不同于内部深灰褐蜡笔轮廓，也不同于透明裁切留白。生成前必须为每件明确 `cutline: yes/no`。

- `cutline: yes`：可独立拿取、移动和裁切的主体贴纸、关联物件、照片框／承托卡、记录卡、完整装饰簇。使用温暖白或浅米白的不规则手作切边，沿元素或装饰簇的整体剪影包围；宽度在同套中视觉一致，但不要求固定像素。
- `cutline: no`：需要直接融入页面的氛围底纹、色块涂抹、区域填充、分区条、连接线、箭头或轨迹。它们保留自然透明边缘，不再套一圈封闭白边。
- 混合用途元素按主要使用方式选择，不得在生成后随意统一补边。若一个装饰簇作为单一逻辑元素交付，只围住整簇，不给簇内每个小点重复描边。
- 一个逻辑元素必须形成单一连通剪影，或由共同底形／共同切边明确连成一簇。彼此分开的物件若会各自得到切边，就必须按多个元素计数；在严格十件规划中应改选一个物件，不得用文字把多个独立贴纸合称为一件。
- 禁止双层白边、纯矢量般均匀硬边、荧光洋红残边，以及把内部蜡笔轮廓误作外圈切边。

## 画布与禁止项

- 在一张横向母版中放置严格十个逻辑元素，完整可见、互不重叠，并保留明显空隙；有切边元素按切边外缘计算间距。
- 目标背景是真正透明；不生成文字、编号、乱码、Logo、水印、品牌、已知角色或在世艺术家仿作。
- 视觉参考只提供共同画法、材质、角色概括、趣味密度和完成度；主体身份与内容事实只来自用户照片。不得复制参考图的主体、姿态、构图、道具、文字、背景或精确配色。
